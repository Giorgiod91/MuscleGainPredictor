# Muscle Gain Predictor

## Overview
This project aims to predict **muscle gain** based on various factors like **protein intake**, **age**, **exercise type**, and **energy intake**. Inspired by machine learning concepts from **Andrej Karpathy** and **Andrew Ng**, I'm using this project to practice and apply what I’ve learned.

Using a **study dataset**, the goal is to explore how protein intake and other factors affect **lean body mass (LBM) changes**. Eventually, I want to predict how much muscle a person can build based on their features like weight, protein intake, age, and exercise type.

## Approach

1. **Data Exploration & Visualization**  
   Visualizing relationships between factors like protein intake, LBM change, age, energy intake, and exercise type.

2. **Linear Regression**  
   Using **linear regression** to predict LBM change per week based on features such as protein intake and age. Multiple features will be considered for prediction.

3. **Future Work**  
   Implement a model to predict muscle gain based on new user data. Explore other algorithms like decision trees and random forests for better accuracy.

## Data
The dataset contains the following columns:
- **Protein intake (g/kg/day)**
- **LBM change per week (kg/wk)**
- **Age (years)**
- **Energy intake (kcal/kg/day)**
- **Type of exercise**, and more.
